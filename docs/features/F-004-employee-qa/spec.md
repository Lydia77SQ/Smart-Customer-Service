# F-004 员工提问并获得系统答复功能规格

## 1. 功能身份

- Feature ID：F-004
- 功能名称：员工提问并获得系统答复
- 所属版本：MVP
- 主要角色：员工
- 来源需求：S-002、BR-001、BR-002、BR-003、BR-004、BR-005、BR-016
- 依赖 Feature：F-001
- 对应页面/视图候选：员工咨询工作台（对话区）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工发送问题后，系统形成咨询工单并给出可观察答复：高置信直接作答、反问补信息，或基于启用中知识的生成答复。

## 3. 前置条件与触发条件

- 前置条件：用户已登录；当前工单不存在或处于「AI 接待中」（已完结须新开咨询，见 F-005 / F-011）
- 触发条件：员工在员工咨询工作台发送一条问题

## 4. 功能范围

### 包含

- 首条提问创建咨询工单，状态为 AI 接待中
- 标准问答高置信匹配（阈值 0.8）则直接作答，不再反问或生成
- 未达阈值则意图识别：模糊只反问；清晰则结合长期画像与最近 3 轮对话改写后检索生成
- 匹配与检索只使用启用中的知识
- 每轮按规则更新该账号长期画像（界面不展示）
- 系统答复作为消息写入同一工单

### 不包含

- 查看历史列表（F-005）
- 转人工（F-006）
- 坐席智能回答（F-009，共用路径语言但结果只给坐席）
- 知识上传与启停（F-012 / F-013）
- 界面编辑画像、导出会话

## 5. 主流程

1. 员工发送问题。若尚无当前工单，创建咨询工单为 AI 接待中。
2. 员工问题写入消息。
3. 用启用中的标准问答做高置信匹配：达到 0.8 则将该答案作为系统消息返回，结束本轮。
4. 否则做意图识别：模糊则只产生反问消息；清晰则带长期画像与最近 3 轮（不足则全用）改写提问，对启用中知识做语义与关键词检索、混合排序后生成答复，写入系统消息。
5. 本轮按规则更新该账号长期画像。

## 6. 异常与边界流程

- 无启用中知识且无法高置信直出：不得假装引用制度；可反问或明确无法依据知识作答，并仍保留工单。
- 对话 / 向量化 / 重排序不可用：不得给出伪装成知识依据的答复；提示暂时无法自动答疑，工单保持 AI 接待中，员工可转人工。
- 工单已是待处理 / 处理中 / 已完结：本 Feature 不对其自动发言（处理中由 F-008；已完结由 F-005 / F-011 拒绝发送）。
- 续聊同一 AI 接待中工单：不新建工单，追加消息后重复主流程。

## 7. 业务规则与不变量

- BR-001：不允许无工单对话。
- BR-002：达阈值只直出，不走反问与生成。
- BR-003：意图模糊不得直接生成知识答案。
- BR-004：改写不得拼入最近 3 轮以外的全量历史。
- BR-005：画像只用于改写，界面不展示、不提供手工编辑。
- BR-016：停用知识不得参与本轮匹配与生成。
- BR-007 的前半约束：仅 AI 接待中才自动对外发言。

## 9. 权限、隐私与安全约束

- 答复不得把其他员工的工单内容当作知识。
- 画像与密钥不得出现在员工可见界面。
- 真实模型密钥只存在配置中，规格与文档只写服务类别。

## 10. 外部服务与降级边界

- 依赖服务：对话大模型、向量化、重排序
- 完整验收需要的权限：可用的模型与额度、至少一篇启用中知识（直出与生成路径）
- 缺失时允许的降级：提示无法自动答疑，保留转人工；不得用编造制度顶替
- 降级时不得宣称：AI 答疑已完整联调通过

## 11. 验收标准

### AC-F004-01 首问建单并得到系统答复

- Given：已登录员工且无当前进行中工单
- When：员工发送一个问题
- Then：产生一条 AI 接待中工单，员工能看到自己的问题以及一条系统答复（直出、反问或生成三者之一）
- 验证类型：agent

### AC-F004-02 高置信标准问答直接作答

- Given：启用中的标准问答与员工问题相似度达到约定阈值 0.8
- When：员工发送该问题
- Then：系统返回该标准答案，且本轮不再出现反问或检索生成式答复
- 验证类型：agent

### AC-F004-03 意图模糊只反问

- Given：标准问答未达阈值，意图被判定为模糊
- When：员工发送该问题
- Then：系统只发出反问、要求补充细节，不给出知识生成答案
- 验证类型：agent

### AC-F004-04 停用知识不参与答疑

- Given：某文档已停用，且启用中知识无法覆盖该问题
- When：员工发送本应由该停用文档才能回答的问题
- Then：系统答复不引用该停用文档的内容作为依据
- 验证类型：agent

### AC-F004-05 外部能力不可用时降级

- Given：对话或向量化能力不可用
- When：员工发送问题
- Then：工单仍为 AI 接待中，员工看到无法自动答疑的说明，而不是伪装的知识答案
- 验证类型：external
