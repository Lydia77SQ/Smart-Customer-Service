# UI 设计说明书

依据方案 D：场景学飞书服务台（干净办公、内部求助），坐席桌面学智齿三栏 Inbox。页面从已确认 Feature / AC 推导，不新增业务按钮或角色。

---

## 风格调研摘要

### 视觉风格

- **内部服务台 / 专业克制** — 白底、细分割线、信息密度适中；坐席台用三栏而不是门户分类墙。圆角 8px，不用超过 12px 的软圆角。文字全中文。

### 配色方案

| 用途 | 色值 |
|---|---|
| Off-Black 正文 | #18181B |
| Primary | #2563EB |
| Primary 浅底 | #EFF6FF |
| 页面底 | #F4F4F5 |
| 卡片 / 面板 | #FFFFFF |
| 分割线 | #E4E4E7 |
| 次要文字 | #71717A |
| 成功 / 启用 | #059669 |
| 警告 / 待处理 | #D97706 |
| 危险 / 停用 / 错误 | #DC2626 |
| 已完结灰 | #A1A1AA |
| Tonal Focus（当前工单状态条） | #1D4ED8 填充，白字 |

工单状态色：AI 接待中 = Primary；待处理 = 警告；处理中 = 成功；已完结 = 已完结灰。

### 字体搭配

- 标题 Outfit（字距 -0.04em）
- 正文 Geist / Inter
- 界面显示文案一律中文

### 关键 UX 规则

1. 已登录后顶部始终提供三个工作台入口，切换不重新登录。
2. 已完结咨询：输入框禁用，转人工 / 发送 / 结单等动作不可用。
3. 智能回答建议只出现在坐席右栏，从不进入员工气泡。
4. 知识停用后列表仍在，用「已停用」标签，不从列表消失。
5. 交互控件覆盖可用、禁用、悬停、按下、聚焦五态；错误用文案说明，不静默失败。

### 界面名称：登录与注册

#### Feature / AC 追踪

| Feature | AC | 本界面负责的可观察结果 |
|---|---|---|
| F-001 | AC-F001-01 | 正确凭证后进入系统并显示当前用户 |
| F-001 | AC-F001-02 | 错误密码拒绝登录、不进入工作台 |
| F-001 | AC-F001-03 | 未登录直接进工作台被拦回本页 |
| F-002 | AC-F002-01 | 注册成功后可用该账号登录 |
| F-002 | AC-F002-02 | 账号名冲突拒绝创建 |

#### 布局结构

- 整体布局：单栏居中卡片，浅灰页面底
- 无左侧导航
- 主内容区：产品名「智能客服系统」、登录表单；可切换到注册表单（同一卡片内 Tab，不是第三个角色）
- 底部：简短说明「内部 IT / 行政支持」

#### 组件清单

| 区域 | 组件类型 | 内容/数据 | 交互行为 |
|---|---|---|---|
| 卡片标题 | 标题 | 智能客服系统 | 无 |
| 模式切换 | Tab | 登录 / 注册 | 切换表单，不提交 |
| 账号 | 文本输入 | 占位：请输入账号 | 聚焦描边 Primary |
| 密码 | 密码输入 | 占位：请输入密码 | 不回显明文 |
| 主按钮 | 按钮 | 登录 或 创建账号 | Enabled 可点；空表单 Disabled |
| 错误条 | 内联提示 | 账号或密码不正确 / 该账号名已被占用 | 失败时出现，成功时消失 |

未登录访问工作台时停留本页并提示「请先登录」（AC-F001-03 / AC-F003-02 的拦截入口）。

#### 示例数据

- 登录成功身份：账号 `wang.li`，显示名「王丽」
- 冲突账号：`wang.li`（已存在）再注册 → 「该账号名已被占用」

### 界面名称：员工咨询工作台

#### Feature / AC 追踪

| Feature | AC | 本界面负责的可观察结果 |
|---|---|---|
| F-003 | AC-F003-01 | 顶栏切到坐席 / 知识维护再回来，不重新登录 |
| F-003 | AC-F003-02 | 未登录不能进入本页（回登录页） |
| F-004 | AC-F004-01 | 首问后出现工单对话与一条系统答复 |
| F-004 | AC-F004-02 | 高置信时直接答案气泡，无反问 |
| F-004 | AC-F004-03 | 模糊意图只出现反问气泡 |
| F-004 | AC-F004-04 | 答复不把已停用文档当依据（文案/引用区不出现该文档名） |
| F-004 | AC-F004-05 | 模型不可用时出现「暂时无法自动答疑」说明，无伪装答案 |
| F-005 | AC-F005-01 | 左侧只列自己的咨询 |
| F-005 | AC-F005-02 | 未完结可在输入框发送 |
| F-005 | AC-F005-03 | 已完结输入框 Disabled，发送被拒 |
| F-006 | AC-F006-01 | 转人工后状态变为待处理，提示等待对接人 |
| F-006 | AC-F006-02 | （坐席列表验证，本页只保证转人工前状态为 AI 接待中） |
| F-006 | AC-F006-03 | 已完结「转人工」Disabled |

无导出按钮。无画像编辑入口。

#### 布局结构

- 整体布局：顶栏 + 下方左右分栏
- 顶栏：产品名、当前用户「王丽」、工作台切换（员工咨询 / 坐席接待 / 知识维护，当前项高亮）、退出
- 左侧：我的咨询列表（状态色点 + 标题 + 时间）；底部「新咨询」
- 主内容区：对话气泡流 + 底栏（输入框在左，转人工与发送在右、同一行、文字不换行）
- 无右侧知识栏（避免做成坐席台）

#### 组件清单

| 区域 | 组件类型 | 内容/数据 | 交互行为 |
|---|---|---|---|
| 顶栏切换 | 水平导航 | 员工咨询、坐席接待、知识维护 | 点击切换工作台 |
| 咨询列表 | 列表 | 见示例数据 | 点击打开对话；当前项浅蓝底 |
| 新咨询 | 按钮 | 新咨询 | 清空为可发送的新会话 |
| 状态条 | Tonal Focus 条 | 如「处理中 · 等待对接人」 | 只读 |
| 消息流 | 气泡 | 员工右、系统/坐席左 | 滚动到底部 |
| 转人工 | 次按钮 | 转人工 | 仅 AI 接待中 Enabled |
| 输入框 | 多行输入 | 占位：描述你的 IT 或行政问题 | 已完结 Disabled |
| 发送 | 主按钮 | 发送 | 已完结 / 空内容 Disabled |

#### 示例数据

咨询列表至少 2 条：

| 标题摘要 | 状态 | 时间 |
|---|---|---|
| VPN 连不上公司内网 | 处理中 | 今天 14:12 |
| 工牌补办要找谁 | 已完结 | 昨天 09:40 |

对话示例（VPN 单）：

- 员工：公司 VPN 连不上，提示认证失败。
- 系统：请补充你用的是 Windows 还是 Mac，以及大约从什么时候开始失败。
- 员工：Windows。今天早上开始的。
- 坐席：已为你重置了 VPN 口令，请用邮件里的新密码再试。

已完结单「工牌补办」：输入框禁用，转人工禁用，可见历史气泡但无发送。

### 界面名称：坐席接待工作台

#### Feature / AC 追踪

| Feature | AC | 本界面负责的可观察结果 |
|---|---|---|
| F-003 | AC-F003-01 | 顶栏三端切换保持登录 |
| F-007 | AC-F007-01 | 待处理列表可打开并接入，状态变处理中，可见历史 |
| F-007 | AC-F007-02 | 处理中时员工再发问，对话区不出现新的自动系统答复 |
| F-007 | AC-F007-03 | 已完结工单不能再点成接入成功 |
| F-006 | AC-F006-02 | 列表不出现从未转人工的 AI 接待中单 |
| F-008 | AC-F008-01 | 发送后员工侧同步（员工台验证）；本页对话立即出现坐席气泡 |
| F-008 | AC-F008-02 | 已完结发送 Disabled |
| F-008 | AC-F008-03 | 建议区文本在未发送时不进入中间消息流 |
| F-009 | AC-F009-01 | 右栏出现建议，中间员工消息流无该文本 |
| F-009 | AC-F009-02 | 不点采用/发送则消息流不增加建议 |
| F-009 | AC-F009-03 | 模型失败时右栏失败说明，中间无新系统消息 |
| F-010 | AC-F010-01 | 分类选择后当前工单展示该标签 |
| F-010 | AC-F010-02 | 已完结分类控件 Disabled |
| F-011 | AC-F011-01 | 结单后双方发送禁用 |
| F-011 | AC-F011-02 | 无「重新打开」按钮 |
| F-011 | AC-F011-03 | 待处理未接入时结单 Disabled |

#### 布局结构

- 整体布局：顶栏 + 三栏 Inbox
- 左侧：工单列表，筛选项「待处理 / 处理中」（默认待处理）；不提供 AI 接待中筛选项
- 中栏：对话 + 底栏输入与发送
- 右栏：工单状态（Tonal Focus）、接入、分类、智能回答、结单

#### 组件清单

| 区域 | 组件类型 | 内容/数据 | 交互行为 |
|---|---|---|---|
| 列表筛选 | 分段控件 | 待处理、处理中 | 切换列表数据 |
| 工单列表 | 列表 | 见示例 | 点击打开；待处理可点「接入」 |
| 接入 | 主按钮（右栏） | 接入处理 | 仅待处理 Enabled |
| 消息流 | 气泡 | 员工 / 系统 / 坐席 | 只读历史 + 新坐席消息 |
| 输入框 | 多行输入 | 占位：回复员工 | 仅处理中 Enabled |
| 发送 | 主按钮 | 发送 | 处理中且非空 Enabled |
| 分类 | 下拉 | IT-网络、IT-账号、行政-工牌、行政-场地 | 未完结可改 |
| 智能回答 | 按钮 + 建议文本区 | 获取建议 | 写入右栏；「填入输入框」不直接发 |
| 结单 | 危险按钮 | 结束工单 | 仅处理中 Enabled |

无重新打开、无导出、无技能组。

#### 示例数据

待处理列表：

| 员工 | 摘要 | 等待 |
|---|---|---|
| 王丽 | VPN 连不上公司内网 | 12 分钟 |
| 陈浩 | 会议室投影仪没有画面 | 3 分钟 |

处理中当前单：

- 状态：处理中
- 分类：IT-网络（可改为 IT-账号）
- 建议区示例：「请确认是否使用公司门户的 VPN 客户端，并尝试忘记密码后用邮箱验证码重置。」——此段只在右栏，未点填入/发送前中间气泡没有这句话。

### 界面名称：知识维护工作台

#### Feature / AC 追踪

| Feature | AC | 本界面负责的可观察结果 |
|---|---|---|
| F-003 | AC-F003-01 | 顶栏切换保持登录 |
| F-012 | AC-F012-01 | 上传成功后列表出现且状态为启用 |
| F-012 | AC-F012-02 | 非 Markdown 拒绝并提示仅支持 Markdown |
| F-012 | AC-F012-03 | 入库失败条目不显示为启用可用 |
| F-013 | AC-F013-01 | 停用后标签变为已停用（答疑效果在员工台验证） |
| F-013 | AC-F013-02 | 再次启用后标签恢复启用 |
| F-013 | AC-F013-03 | 停用后行仍在列表，不是删除 |

#### 布局结构

- 整体布局：顶栏 + 上工具条 + 下方文档表（数据密集用通栏表格，不必三栏）
- 工具条：上传 Markdown、格式说明「仅支持 .md」
- 主内容：文档表（名称、状态、更新时间、启用/停用）

#### 组件清单

| 区域 | 组件类型 | 内容/数据 | 交互行为 |
|---|---|---|---|
| 上传 | 文件按钮 | 选择 .md | 成功刷新表格；非 md 错误提示 |
| 失败提示 | 内联错误 | 仅支持 Markdown / 入库未生效 | 失败时出现 |
| 文档表 | 表格 | 见示例 | 行内开关启停 |
| 状态标签 | 标签 | 启用 / 已停用 / 未生效 | 只读展示 |
| 启停 | 开关 52×32px | 开=启用 | 未生效行 Disabled |

无删除按钮、无 docx/pdf 入口、无目录树权限。

#### 示例数据

| 文档名称 | 状态 | 更新时间 |
|---|---|---|
| VPN 接入说明.md | 启用 | 2026-08-28 18:20 |
| 工牌补办流程.md | 已停用 | 2026-08-27 11:05 |
| 会议室预约须知.md | 启用 | 2026-08-26 09:12 |

「工牌补办流程.md」停用后仍占一行，开关为关，标签「已停用」。

## 追踪自检

| 检查 | 结果 |
|---|---|
| 每个 MVP Feature 有界面 | F-001～F-013 均映射到上表四页之一 |
| 涉及 UI 的 AC 有交互 | 已按 AC 落到按钮、列表、禁用态或提示 |
| 无范围外能力 | 无导出、无重开、无分权隐藏、无非 md、无画像编辑、无 FAQ 门户墙 |
| 公共导航 | 仅 F-003，不单独发明第四工作台 |

无独立 UI 的业务结果：无。F-004-04 / F-013-01 的「答疑不用停用文档」由员工对话 + 知识列表状态共同观察。
