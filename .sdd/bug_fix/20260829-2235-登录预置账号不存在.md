# Bug 修复报告：真实登录预置账号不存在

## 用户原话

> 两个账号登录均显示账号或密码不正确

## 经验回查

- 是否已有相关经验：是
- 相关经验：
  - T-001：Mock 登录凭证以 `docs/api-contracts.md` 示例为准；不要把原型密码框里的掩码当成真实密码
  - T-012：`VITE_USE_MOCK=false` 时 login 走真实 `/api/auth/login`；Tester 超出范围已记录运行时库无契约示例账号
- 为什么仍然犯错：缺种账号被标成可选，未写入 `init_db`；登录页把所有异常都映射成同一句失败文案，后端未启动时也会像密码错误

## 问题分析

- 现象：登录页使用两个契约示例账号均提示「账号或密码不正确」，无法进入工作台
- 影响范围：F-001 用户登录、T-012/T-013 用户门禁验收（`VITE_USE_MOCK=false`）
- 直接原因：真实 `accounts` 表没有与登录页预填 / Mock 对齐的账号；未知账号按契约返回 401 同一文案
- 根本原因：Plan.md / F-001 spec 允许预置账号，但 `init_db` 只建表不种数据。登录页 `catch` 未区分 `UNAUTHORIZED` 与网络失败
- 涉及文件：`backend/src/db/session.py`、`backend/src/db/seed.py`、`frontend/src/pages/LoginPage.vue`、`frontend/src/utils/error.ts`
- 涉及规范或契约：`docs/api-contracts.md` API-F001-01；`docs/features/F-001-user-login/spec.md`（账号可来自注册或预置）；`docs/Plan.md`（F-002 不是 F-001 唯一账号来源）

## 修复方案

- 修改文件：
  - `backend/src/db/seed.py`（新建）
  - `backend/src/db/session.py`
  - `backend/tests/test_seed_demo_accounts.py`（新建）
  - `frontend/src/pages/LoginPage.vue`
  - `frontend/src/utils/error.ts`
  - `.sdd/experience.md`
- 修改说明：
  - `init_db` 在建表后幂等写入契约示例账号（已存在则跳过，不覆盖密码）
  - 已对运行时库执行一次 `scripts/init_db.py`，演示账号已落入 `backend/data/service_robot.db`
  - 登录页仅在 `UNAUTHORIZED` 时显示「账号或密码不正确」；无法连接后端时提示「无法连接服务，请确认后端已启动」
