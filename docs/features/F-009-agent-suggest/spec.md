# F-009 坐席获取智能回答建议功能规格

## 1. 功能身份

- Feature ID：F-009
- 功能名称：坐席获取智能回答建议
- 所属版本：MVP
- 主要角色：坐席
- 来源需求：S-006、BR-004、BR-008、BR-016
- 依赖 Feature：F-007
- 对应页面/视图候选：坐席接待工作台（建议区）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

坐席对处理中工单请求智能回答后，得到与员工答疑同一套路径语言的建议文本；未确认发出前员工看不到。

## 3. 前置条件与触发条件

- 前置条件：工单为处理中；用户已登录
- 触发条件：坐席请求智能回答

## 4. 功能范围

### 包含

- 使用与 F-004 相同的路径：高置信直出 → 意图（模糊则建议反问口径）→ 画像与最近 3 轮改写 → 启用中知识检索生成
- 结果写入建议答复，仅坐席可见
- 坐席可丢弃或交给 F-008 发出

### 不包含

- 自动发给员工（BR-008）
- 知识上传与启停
- 个人话术库

## 5. 主流程

1. 坐席在处理中工单请求智能回答。
2. 系统按共用答疑路径生成建议。
3. 坐席看到建议；员工对话不变。

## 6. 异常与边界流程

- 工单非处理中：拒绝生成建议。
- 外部能力不可用：提示无法生成建议，不向员工发任何自动消息。
- 停用知识：不得作为建议依据（BR-016）。

## 7. 业务规则与不变量

- BR-008：建议不是员工消息。
- BR-004：改写使用画像与最近 3 轮。
- BR-016：只使用启用中知识。
- 不改变工单状态。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 咨询工单、消息、长期画像、启用中知识 | 生成建议的输入 | F-004 / F-012 / F-013 |
| 创建 | 建议答复 | 仅坐席可见 | F-009 |

## 9. 权限、隐私与安全约束

- 建议不得展示其他工单的隐私内容。
- 密钥不进界面。

## 10. 外部服务与降级边界

- 依赖服务：对话大模型、向量化、重排序
- 完整验收需要的权限：与 F-004 相同
- 缺失时允许的降级：坐席只能手写回复
- 降级时不得宣称：智能回答已完整联调通过

## 11. 验收标准

### AC-F009-01 生成仅坐席可见的建议

- Given：工单为处理中
- When：坐席请求智能回答
- Then：坐席看到一条建议答复，员工对话中不出现该文本
- 验证类型：agent

### AC-F009-02 未确认不得成为员工消息

- Given：建议已生成
- When：坐席不发送
- Then：工单消息列表不增加该建议内容
- 验证类型：auto

### AC-F009-03 模型不可用时不骚扰员工

- Given：对话或向量化不可用
- When：坐席请求智能回答
- Then：坐席得到失败说明，员工侧无新的系统消息
- 验证类型：external
