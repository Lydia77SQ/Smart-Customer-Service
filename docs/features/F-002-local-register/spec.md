# F-002 本地账号注册功能规格

## 1. 功能身份

- Feature ID：F-002
- 功能名称：本地账号注册
- 所属版本：MVP
- 主要角色：内部用户
- 来源需求：S-001（本地账号）
- 依赖 Feature：无
- 对应页面/视图候选：登录页上的注册视图，或独立注册页
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

尚未有账号的人提交注册信息后，获得可登录的本地账号。

## 3. 前置条件与触发条件

- 前置条件：用户尚未持有该账号名
- 触发条件：用户在注册入口提交账号与密码

## 4. 功能范围

### 包含

- 创建本地账号
- 账号名冲突时拒绝创建并提示
- 注册成功后该账号可用于 F-001 登录

### 不包含

- 登录本身（F-001）
- 管理员发放账号、邮箱验证、SSO
- 停用 / 删除账号

## 5. 主流程

1. 用户提交账号名与密码。
2. 系统确认账号名未被占用。
3. 系统创建有效账号。
4. 用户可使用该账号登录。

## 6. 异常与边界流程

- 账号名已被占用：不创建新账号，提示更换。
- 必填项缺失：拒绝创建。
- 注册成功不自动视为已登录：用户需走 F-001（若产品在实现时选择注册后自动登录，仍须满足 F-001 的已登录结果，但不改变本 Feature 的「获得账号」边界）。

## 7. 业务规则与不变量

- MVP 账号类型不区分角色。
- 新账号长期画像为空，由后续对话抽取。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 账号 | 判断账号名是否已被占用 | F-002 |
| 创建 | 账号 | 产生可登录身份 | F-002 |

## 9. 权限、隐私与安全约束

- 密码不得以明文写入业务文档或界面回显。
- 任何人不得通过注册接口改写已有账号。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：可用预置账号代替自助注册做登录验收，但不得宣称本 Feature 已交付
- 降级时不得宣称：自助注册已可用

## 11. 验收标准

### AC-F002-01 注册成功

- Given：该账号名尚未被占用
- When：用户提交合法账号名与密码
- Then：系统产生有效账号，之后可用该凭证登录
- 验证类型：auto

### AC-F002-02 账号名冲突

- Given：系统已存在同名账号
- When：用户用该账号名注册
- Then：系统拒绝创建，原账号保持不变
- 验证类型：auto
