# F-005 查看并继续自己的咨询功能规格

## 1. 功能身份

- Feature ID：F-005
- 功能名称：查看并继续自己的咨询
- 所属版本：MVP
- 主要角色：员工
- 来源需求：S-003、BR-009、BR-010、BR-011、BR-013
- 依赖 Feature：F-004
- 对应页面/视图候选：员工咨询工作台（列表 + 对话）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工能看到自己的历史咨询并打开查看全程；未完结的可以继续发言，已完结的只能看。

## 3. 前置条件与触发条件

- 前置条件：用户已登录；系统中存在该用户发起的工单
- 触发条件：员工打开历史列表或选中某条咨询

## 4. 功能范围

### 包含

- 列出当前用户自己的咨询
- 打开后看到该工单全部消息（含系统与坐席）
- AI 接待中 / 待处理 / 处理中允许继续发送（发送后的答疑或人工路径分别由 F-004 / F-008 负责）
- 已完结只读，拒绝再发
- 不提供导出或下载

### 不包含

- 看到他人工单
- 重新打开已完结工单（F-016）
- 转人工按钮的业务结果（F-006）

## 5. 主流程

1. 员工打开自己的咨询列表。
2. 员工选择一条咨询。
3. 系统展示该工单全部消息。
4. 若未完结，员工可输入并发送；若已完结，输入发送被拒绝。

## 6. 异常与边界流程

- 列表中不出现其他账号的工单。
- 打开不存在或不属于自己的工单：视为不存在，拒绝展示。
- 已完结点击发送：提示已完结，消息不写入。
- 无历史：展示空列表，而不是他人数据。

## 7. 业务规则与不变量

- BR-009、BR-010：已完结不可发言、不可重开。
- BR-011：员工只看自己的咨询。
- BR-013：不提供导出下载。
- 待处理 / 处理中续发员工消息：不触发系统自动对外答复（BR-007），等待坐席。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 咨询工单 | 仅发起人自己的工单 | F-004 |
| 读取 | 消息 | 展示全程 | F-004 |

## 9. 权限、隐私与安全约束

- 不得通过猜测标识查看他人工单。
- 界面不提供导出入口。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F005-01 只能看到自己的咨询

- Given：账号 A、B 各有至少一条咨询
- When：以 A 登录查看历史
- Then：列表与详情中只有 A 的工单和消息
- 验证类型：auto

### AC-F005-02 未完结可继续

- Given：A 有一条 AI 接待中工单
- When：A 打开该工单并发送新消息
- Then：消息写入同一工单，员工能在对话中看到
- 验证类型：auto

### AC-F005-03 已完结不能再发

- Given：A 有一条已完结工单
- When：A 打开该工单并尝试发送
- Then：系统拒绝写入新消息并提示已完结
- 验证类型：auto
