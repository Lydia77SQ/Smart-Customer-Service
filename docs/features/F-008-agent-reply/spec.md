# F-008 坐席向员工发送回复功能规格

## 1. 功能身份

- Feature ID：F-008
- 功能名称：坐席向员工发送回复
- 所属版本：MVP
- 主要角色：坐席
- 来源需求：S-005
- 依赖 Feature：F-007
- 对应页面/视图候选：坐席接待工作台（对话输入）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

坐席在处理中工单发出的回复，出现在该员工同一条咨询的对话中。

## 3. 前置条件与触发条件

- 前置条件：工单为处理中
- 触发条件：坐席提交一条回复（手写或采用建议后发出）

## 4. 功能范围

### 包含

- 坐席发送消息写入该工单
- 员工刷新或持续查看时能看到该条人工消息
- 可将 F-009 的建议答复确认为本 Feature 的发出内容（发出动作属于本 Feature）

### 不包含

- 生成建议（F-009）
- 结单、分类
- 自动把建议发给员工

## 5. 主流程

1. 坐席打开处理中工单。
2. 坐席输入回复或采用建议后发送。
3. 消息以坐席身份写入工单。
4. 员工在同一咨询中看到该消息。

## 6. 异常与边界流程

- 工单已完结：拒绝发送（BR-009）。
- 工单仍为待处理：拒绝发送，须先接入。
- 空内容：拒绝发送。

## 7. 业务规则与不变量

- BR-008：未确认的建议不是本 Feature 的消息。
- BR-009：已完结不能发。
- 一对一：回复只进入该工单，不同步给其他员工。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 咨询工单 | 确认处理中 | F-004 |
| 读取 | 建议答复 | 可选，坐席确认发出时 | F-009 |
| 创建 | 消息 | 坐席回复 | F-008 |

## 9. 权限、隐私与安全约束

- 坐席不能把消息写入他未可见的工单。
- 不提供导出。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F008-01 人工回复同步到员工

- Given：工单为处理中
- When：坐席发送一条回复
- Then：该员工在同一咨询中能看到这条坐席消息
- 验证类型：auto

### AC-F008-02 已完结不能回复

- Given：工单已完结
- When：坐席尝试发送回复
- Then：系统拒绝，对话中不新增消息
- 验证类型：auto

### AC-F008-03 建议未发出前员工看不到

- Given：坐席已生成建议答复但尚未发送
- When：员工查看该咨询
- Then：对话中不出现该建议文本
- 验证类型：auto
