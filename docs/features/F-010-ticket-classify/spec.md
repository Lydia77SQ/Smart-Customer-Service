# F-010 坐席为工单分类功能规格

## 1. 功能身份

- Feature ID：F-010
- 功能名称：坐席为工单分类
- 所属版本：MVP
- 主要角色：坐席
- 来源需求：S-007
- 依赖 Feature：F-007
- 对应页面/视图候选：坐席接待工作台（当前工单）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

坐席为未完结工单打上业务标签后，该工单带有可观察的分类。

## 3. 前置条件与触发条件

- 前置条件：工单为待处理或处理中
- 触发条件：坐席选择或更改分类

## 4. 功能范围

### 包含

- 为工单写入或更新业务分类标签
- 在坐席当前工单视图上能看到分类

### 不包含

- 报表、质检、按分类自动派单
- 结单（F-011）
- 切片级或知识文档分类

## 5. 主流程

1. 坐席打开未完结工单。
2. 坐席选择分类。
3. 工单显示该分类。

## 6. 异常与边界流程

- 已完结：拒绝改分类。
- 未选择分类即结单：允许（分类非结单前置），本 Feature 不强制。

## 7. 业务规则与不变量

- 分类可改到结单为止。
- 分类不改变工单状态。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 咨询工单 | 确认未完结 | F-004 |
| 写入 | 工单分类 | 打标签 | F-010 |

## 9. 权限、隐私与安全约束

- 仅能对坐席可见工单分类。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F010-01 分类写入工单

- Given：工单为处理中
- When：坐席选择一个业务分类
- Then：该工单展示所选分类
- 验证类型：auto

### AC-F010-02 已完结不能改分类

- Given：工单已完结
- When：坐席尝试更改分类
- Then：系统拒绝，分类保持结单时的值
- 验证类型：auto
