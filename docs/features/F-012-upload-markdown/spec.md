# F-012 上传 Markdown 并入库功能规格

## 1. 功能身份

- Feature ID：F-012
- 功能名称：上传 Markdown 并入库
- 所属版本：MVP
- 主要角色：知识维护者
- 来源需求：S-008、BR-012、BR-015
- 依赖 Feature：F-001
- 对应页面/视图候选：知识维护工作台
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

维护者上传 Markdown 成功入库后，文档默认启用，后续答疑可以使用该材料。

## 3. 前置条件与触发条件

- 前置条件：用户已登录
- 触发条件：用户提交一个 Markdown 文件

## 4. 功能范围

### 包含

- 仅接受 Markdown
- 入库后产生知识文档、知识切片与标准问答
- 入库成功默认启用
- 在知识工作台看到已入库文档

### 不包含

- 启用 / 停用（F-013）
- 非 Markdown、外部网盘、版本回滚、权限目录（F-019）
- 删除文档（用停用代替）

## 5. 主流程

1. 维护者选择 Markdown 并上传。
2. 系统处理并入库。
3. 文档处于已入库且启用。
4. 后续 F-004 / F-009 可以使用该文档。

## 6. 异常与边界流程

- 非 Markdown：拒绝入库，提示仅支持 Markdown。
- 处理失败：文档不进入启用可用，提示未生效。
- 空文件：拒绝入库。

## 7. 业务规则与不变量

- BR-012：只接受 Markdown。
- BR-015：入库成功默认启用。
- 切片与标准问答不能脱离文档单独存在。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 创建 | 知识文档 | 一篇已入库制度 / 说明 | F-012 |
| 创建 | 知识切片 | 供检索的片段 | F-012 |
| 创建 | 标准问答 | 供高置信直出 | F-012 |

## 9. 权限、隐私与安全约束

- MVP 登录用户均可上传；误传风险接受，V2 分权。
- 上传文件不得执行其中的脚本；只作为知识材料。

## 10. 外部服务与降级边界

- 依赖服务：向量化（入库时）
- 完整验收需要的权限：向量化可用
- 缺失时允许的降级：可保存原文但不得宣称已可供语义检索
- 降级时不得宣称：知识入库已完整可用于答疑

## 11. 验收标准

### AC-F012-01 Markdown 入库默认启用

- Given：已登录用户持有合法 Markdown
- When：用户上传该文件且处理成功
- Then：知识列表出现该文档且为启用；之后员工提问可使用该材料
- 验证类型：agent

### AC-F012-02 拒绝非 Markdown

- Given：用户选择非 Markdown 文件
- When：用户上传
- Then：系统拒绝入库并提示仅支持 Markdown，列表不出现该文件为已启用知识
- 验证类型：auto

### AC-F012-03 入库失败不生效

- Given：文件为 Markdown 但处理失败
- When：用户完成上传动作
- Then：该文档不得作为启用中知识被答疑使用
- 验证类型：auto
