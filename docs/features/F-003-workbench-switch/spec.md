# F-003 三端工作台切换功能规格

## 1. 功能身份

- Feature ID：F-003
- 功能名称：三端工作台切换
- 所属版本：MVP
- 主要角色：内部用户
- 来源需求：S-009、BR-014
- 依赖 Feature：F-001
- 对应页面/视图候选：各工作台公共导航
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

已登录用户无需重新登录，即可在员工咨询、坐席接待、知识维护三个工作台之间切换。

## 3. 前置条件与触发条件

- 前置条件：用户已登录
- 触发条件：用户选择另一个工作台入口

## 4. 功能范围

### 包含

- 从任一工作台进入另外两个工作台
- 切换后保持同一登录身份
- 三个工作台入口在已登录后均可见（MVP 不分权）

### 不包含

- 按角色隐藏入口（F-014）
- 登录、注册
- 各工作台内部的提问、接单、上传等业务动作

## 5. 主流程

1. 已登录用户位于某一工作台。
2. 用户选择员工咨询、坐席接待或知识维护入口。
3. 系统展示对应工作台，登录身份不变。

## 6. 异常与边界流程

- 未登录时切换：拒绝并要求登录（与 F-001 一致）。
- 重复选择当前工作台：保持当前工作台，不退出登录。

## 7. 业务规则与不变量

- 引用 BR-014：切换不得要求重新登录。
- MVP 不因角色拦截任一工作台。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 登录状态 | 确认身份仍有效 | F-001 |

## 9. 权限、隐私与安全约束

- 切换不改变「员工只能看自己的工单」等数据权限（由 F-005 / F-007 执行）。
- 进入坐席台不等于自动接入工单。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F003-01 三端互相切换且保持登录

- Given：用户已登录并处于员工咨询工作台
- When：用户依次进入坐席接待、知识维护，再回到员工咨询
- Then：每次都进入对应工作台，且全程不要求重新登录、身份不变
- 验证类型：agent

### AC-F003-02 未登录不能切换

- Given：用户未登录
- When：用户请求进入任一工作台
- Then：系统拒绝进入并要求登录
- 验证类型：auto
