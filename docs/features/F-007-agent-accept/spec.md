# F-007 坐席接入待处理工单功能规格

## 1. 功能身份

- Feature ID：F-007
- 功能名称：坐席接入待处理工单
- 所属版本：MVP
- 主要角色：坐席
- 来源需求：S-005、BR-007、BR-011
- 依赖 Feature：F-001、F-006
- 对应页面/视图候选：坐席接待工作台（列表 + 对话）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

坐席从待处理列表选择工单并接入后，工单变为处理中；系统不再对该工单自动对外发言。

## 3. 前置条件与触发条件

- 前置条件：用户已登录；存在待处理工单
- 触发条件：坐席选择某条待处理工单并确认接入

## 4. 功能范围

### 包含

- 展示待处理与处理中工单列表
- 打开工单查看完整消息
- 接入后状态变为处理中
- 接入后禁止系统再自动对该工单发言

### 不包含

- 技能组、排队、转交
- 发送回复（F-008）、智能建议（F-009）、分类（F-010）、结单（F-011）
- 查看从未转人工的 AI 接待中工单

## 5. 主流程

1. 坐席打开接待工作台，看到待处理工单。
2. 坐席选中一条并接入。
3. 工单变为处理中，对话上下文可见。

## 6. 异常与边界流程

- 工单已被结单或不再是待处理：拒绝接入并提示状态已变化。
- 已是处理中：允许继续打开查看，不重复「接入」成功提示为新的状态变化。
- 未转人工工单：列表中不出现。

## 7. 业务规则与不变量

- BR-007：接入后系统不再自动对外发言。
- BR-011：坐席可看待处理与处理中；员工侧仍只能看自己的单。
- MVP 不限制「同时只能一名坐席接入」为强互斥账号（同一账号三端）；不引入转交。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 咨询工单、消息 | 列表与上下文 | F-004 |
| 写入 | 咨询工单 | 待处理 → 处理中 | F-007 |

## 9. 权限、隐私与安全约束

- 坐席不可见未转人工咨询。
- 不提供导出。

## 10. 外部服务与降级边界

- 依赖服务：无
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F007-01 接入后变为处理中

- Given：存在待处理工单
- When：坐席接入该工单
- Then：状态变为处理中，坐席能看到转人工前的全部消息
- 验证类型：auto

### AC-F007-02 接入后系统不再自动答复

- Given：工单已是处理中
- When：员工在该工单中再发一条消息
- Then：系统不产生新的自动对外答复
- 验证类型：auto

### AC-F007-03 非待处理不能按接入成功

- Given：工单已完结
- When：坐席尝试将其接入为处理中
- Then：系统拒绝，状态仍为已完结
- 验证类型：auto
