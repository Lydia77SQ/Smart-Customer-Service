# F-001 用户登录功能规格

## 1. 功能身份

- Feature ID：F-001
- 功能名称：用户登录
- 所属版本：MVP
- 主要角色：内部用户
- 来源需求：S-001
- 依赖 Feature：无
- 对应页面/视图候选：登录页
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

内部用户提交有效凭证后进入系统，身份可识别，可继续使用三个工作台。

## 3. 前置条件与触发条件

- 前置条件：系统中已存在该账号（来自 F-002 注册或预置）
- 触发条件：未登录用户在登录入口提交账号与密码

## 4. 功能范围

### 包含

- 用账号和密码登录
- 登录成功后保持有效登录状态，直到用户退出或会话失效
- 登录失败时给出可理解原因，不进入工作台

### 不包含

- 注册（F-002）
- 工作台切换（F-003）
- SSO、找回密码、停用账号

## 5. 主流程

1. 用户打开登录入口并提交账号、密码。
2. 系统核对凭证。
3. 核对通过后建立已登录状态，用户进入系统（默认可进入员工咨询工作台）。

## 6. 异常与边界流程

- 账号不存在或密码错误：拒绝登录，不建立已登录状态。
- 已登录用户再次打开登录入口：保持已登录，或直接进入工作台，不创建第二个身份。
- 用户退出：清除已登录状态，再次使用需重新登录。

## 7. 业务规则与不变量

- 未登录不得使用三个工作台。
- 登录只识别身份，不区分员工 / 坐席 / 知识维护者账号类型。

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 账号 | 核对凭证是否有效 | F-002 |
| 创建 | 登录状态 | 标记当前访问者已识别 | F-001 |

## 9. 权限、隐私与安全约束

- 失败提示不得暴露「账号是否存在」以外的敏感内部信息；密码不得回显、不得写入业务文档。
- MVP 不提供会话导出。

## 10. 外部服务与降级边界

- 依赖服务：无外部身份服务
- 完整验收需要的权限：无
- 缺失时允许的降级：不适用
- 降级时不得宣称：不适用

## 11. 验收标准

### AC-F001-01 登录成功

- Given：系统存在有效账号
- When：用户提交正确凭证
- Then：用户进入系统且能看到当前用户身份
- 验证类型：auto

### AC-F001-02 凭证错误

- Given：系统存在该账号
- When：用户提交错误密码
- Then：系统拒绝登录且不建立已登录状态
- 验证类型：auto

### AC-F001-03 未登录无法使用工作台

- Given：用户未登录
- When：用户直接请求进入任一工作台
- Then：系统拒绝进入并要求登录
- 验证类型：auto
